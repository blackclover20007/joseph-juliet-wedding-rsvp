# Joseph & Juliet Wedding RSVP

A gold-and-white responsive wedding RSVP page for Joseph and Juliet's celebration on Monday, 21 December 2026 at Munondo 11 Events.

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173.

## Notes

This is a static front-end RSVP experience. Submissions are stored in the visitor's browser using `localStorage`; connect the form handler to a database, Formspree, or Google Sheets endpoint for shared response collection.
